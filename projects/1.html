Трекер для збору крипто-токенів

Розробив webapp на React для Telegram який дозволяє користувачам швидко збирати токени у міні іграх. Основні функціональні можливості:

  • Реалізація таймера, що дозволяє налаштовувати інтервали видачі посилань.
  • Інтеграція з Telegram для передачі користувачам повідомлень із посиланнями.
  • Відображення активних таймерів і статистики взаємодії.
  • Гнучкі налаштування для додавання нових міні ігор.

Технології: React, Next.js, JavaScript, Telegram API, REST API.
