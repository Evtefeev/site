Скрипт для обробки платежів

Розробив скрипт для обробки онлайн-платежів через банківські карти. Основні можливості:

  • Інтеграція з платіжними API для обробки транзакцій.
  • Підтримка різних типів платежів (одиночні, підписки).
  • Обробка результатів транзакцій та автоматичне оновлення бази даних про статуси платежів.

Технології: Python, cURL, API платіжних систем.
