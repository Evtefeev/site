Фронтенд-графік для відстеження процесів буріння

Розробив скрипт на JavaScript для відображення даних про процеси буріння у вигляді інтерактивних графіків. Основні можливості:

  • Отримання даних у реальному часі з API для динамічного оновлення графіків.
  • Побудова налаштовуваних графіків із підтримкою масштабування, фільтрації та вибору параметрів.
  • Відображення ключових показників процесу, таких як швидкість буріння, тиск, температура та інші параметри.
  • Адаптивний дизайн для коректного відображення на різних пристроях.

Технології: JavaScript, Chart.js, REST API, HTML, CSS.
