Прототип додатку для бронювання квитків JAVA

Розробив програму на Java для бронювання квитків на потяг із можливістю збереження даних у базу даних. Основні можливості:

  • Інтерфейс для вибору напрямків, дати, часу та класу місць.
  • Обробка запитів користувачів для перевірки доступності квитків у реальному часі.
  • Реєстрація користувачів та збереження інформації про бронювання у базі даних.
  • Захист від дублювання записів та забезпечення цілісності даних.

Технології: Java, JDBC, MySQL, Java Swing для інтерфейсу.
