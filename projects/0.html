Бекенд для телеграм гри

Розробив REST-API на Flask для підтримки Telegram-гри "LearnToEarn". Основні функціональні можливості:

  • Обробка запитів від Telegram-бота для взаємодії з грою.
  • Зберігання даних користувачів, прогресу та ігрової статистики в базі даних.
  • Захист API за допомогою аутентифікації та валідації запитів.
  • Розробка гнучкої архітектури для масштабованості та інтеграції нових функцій.
  • Деплой на Vercel

Технології: Python, Flask, SQLAlchemy, PostgreSQL.
