Телеграм бот для прогнозу погоди

Розробив Telegram-бота, який парсить дані про погоду з веб-сайтів та надсилає користувачам актуальні прогнози. Основні можливості:

  • Парсинг даних з різних погодних сайтів через API або веб-скрапінг.
  • Надсилання користувачам прогнозу погоди на основі їхнього місця розташування або введеного міста.
  • Підтримка запитів на кілька днів вперед із деталями про температуру, вологість, швидкість вітру та інші погодні умови.
  • Повідомлення про зміни погоди або екстремальні погодні умови (шторм, дощ, сніг).

Технології: Python, Telethon, BeautifulSoup (для парсингу), requests, API погоди (OpenWeatherMap).
