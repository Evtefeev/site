Телеграм бот для покупки онлайн-курсів

Розробив Telegram-бота, який надає користувачам зручний інтерфейс для вибору та придбання онлайн-курсів. Основні можливості:

  • Перегляд каталогу курсів із категоріями, описами та цінами.
  • Реалізація функції додавання курсів до кошика та оплати через інтеграцію з платіжною системою QIWI.
  • Система аутентифікації користувачів для збереження історії покупок.
  • Надсилання доступу до курсів після підтвердження оплати.
  • Панель адміністратора для управління курсами та перегляду статистики.

Технології: Python, Telethon, SQLite/MySQL, інтеграція з Telegram API та платіжними API.
