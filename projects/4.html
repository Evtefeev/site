Плагін-парсер для інтернет магазину

Розробив плагін для WordPress, який автоматично оновлює ціни товарів раз на добу з інших магазинів і додає їх на сайт за допомогою сканування баркодів. Основні можливості:

  • Автоматичне отримання даних про ціни через API або парсинг із зовнішніх джерел.
  • Пошук і оновлення товарів на сайті за баркодами для точного зіставлення.
  • Інтеграція з базою даних WordPress для збереження актуальних цін.
  • Панель налаштувань для управління розкладом оновлень та налаштування джерел даних.

Технології: PHP, WordPress API, MySQL, cURL.
